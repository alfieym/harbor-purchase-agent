两条别踩的线

没配就是 no-op

每个 helper 在没配置 Observability 时返回空 span。埋点代码永远可以写，它不会改变业务行为，也不会抛异常——遥测坏了不能把一次 turn 拖下水。

unknown 不是 0

用量报不出来就写 "unknown"，而不是猜一个数。缓存计数只在大于 0 时才计——否则「provider 说没有」和「provider 没报」会被混成一个 0。

为什么单独提 SSE：它是一条不会自己结束的长连接。中间件按路径前缀把它排除在 http.request 之外——否则每开一个流，就多一个永远不 close 的 span，把 trace 环塞满。
