一句话怎么变成参数

模型（ReAct 循环）决定要不要调 product_search，并把自然语言拆进结构化字段。悬停左边句子的片段，右边对应字段高亮。

「给猫买个饮水器， 预算 300 元， 不要塑料的， 5 公斤以内。」 —— 蓝 = 软召回（S3）· 绿 = 硬约束（S2）· 「给猫买」还隐式推断出类目

每个字段由哪一层消费

S2 定「谁进得来」（硬约束，Qdrant filter 的 must 子句）；S3 定「谁排前面」（语义召回 + 精排）。模型把它们都装进同一次工具调用。

端到端实例：币种归一化

真实目录（3700 条）是多币种的（CNY/USD/EUR/JPY/SGD）。「预算 300 元」的 300 是 CNY，但命中的商品原价是 USD / EUR —— 预算过滤和报告都必须换算，否则模型会随机摇摆。
